# GameZone - Tienda de Videojuegos

## Descripción

GameZone es una página web de una tienda de videojuegos desarrollada como parte de la asignatura Frontend I.

El sitio presenta videojuegos destacados mediante un carrusel de imágenes y tarjetas de productos, incorporando un diseño moderno, responsivo y adaptable a distintos dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- GitHub Pages

## Características

- Diseño responsivo para computador, tablet y teléfono.
- Barra de navegación adaptable mediante Bootstrap.
- Carrusel de imágenes de videojuegos.
- Tarjetas de productos utilizando Bootstrap Cards.
- Botones de información.
- Sección de contacto.
- Efectos visuales mediante CSS.
- Uso de Google Fonts.
- Navegación mediante enlaces internos.

## Videojuegos incluidos

- Super Mario Bros.
- Minecraft
- Rocket League
